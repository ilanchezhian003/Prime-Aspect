# Prime Aspect - React Replica

A React + Vite project replica of the Prime Aspect structural engineering consulting firm website.

## Features

- ✅ Multi-page React application with routing
- ✅ Responsive design
- ✅ Fast development with Vite
- ✅ Ready for Netlify deployment
- ✅ All 6 pages: Home, Projects, Services, About, Contact, Blog

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

Opens the app at `http://localhost:3000`

## Build

```bash
npm run build
```

Creates optimized build in the `dist` folder.

## Deployment to Netlify

1. Push to GitHub
2. Connect repository to Netlify
3. Build command: `npm run build`
4. Publish directory: `dist`
5. Deploy!
